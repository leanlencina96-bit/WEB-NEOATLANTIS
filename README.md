# Web de NeoAtlantis

Sitio estático (HTML, CSS y JS puros, sin build) de NeoAtlantis, agencia de presencia digital y automatización.

| Archivo | Qué es |
|---|---|
| `index.html` | Página principal de NeoAtlantis |
| `demo-psicologia.html` | Demo "Espacio Claro": consultorio de psicología con reserva de sesiones simulada |
| `demo-juridico.html` | Demo "Ferrari & Asociados": estudio jurídico con agenda de consultas simulada |

La demo odontológica con turnos reales ("Dental Vértice") vive en otro repositorio y se publica en https://consultorio-dental-flax.vercel.app/.

## Publicar en Vercel

"Add New Project" → importar este repositorio → Framework Preset: **Other** → sin build command → Deploy. Cada push a `main` vuelve a publicar solo.
